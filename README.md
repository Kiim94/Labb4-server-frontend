# Laboration 4

Länk till webbplats: https://laboration4.netlify.app/

## Om uppgiften

Detta är del 2 av 2: frontend delen.

Detta är webbplatsen som har använt Fetch API för att konsumera webbtjänst från del 1 (backend). I frontend delen har sessionStorage använts för att spara tillfälliga tokens. 

När en ny användare är registrerad kan den logga in med sitt användarnamn och lösenord. Vid lyckad inloggning ska man se sin profil bild: där får man se sitt användarnamn, valda email (riktig eller påhittad, jag har ingen kontroll för hur mailen ser ut) samt när användaren skapades. En extra sida har skapats som bara är tillgänglig om man är inloggad.
